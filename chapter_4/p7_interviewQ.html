1️⃣ Core Java break and continue - Interview Question with Answers.

These are common interview question asked in Java Fresher, Junior Developer, and Core Java interviews.

2️⃣ 1. What is the break statement in Java?

Answers

The breakstatement is used to immediately terminate a loop ( for, while, do-while ) or a switch statement.

After break executes, control transfers to the first statement after the loop or switch.

Example: 

for( int i = 1; i <= 5; i++){
    if (i == 3){
        break;
    }
    System.out.println(i);
}

Output:

1
2

3️⃣ 2. What is the continue statement in Java?

Answers

The continuestatement skip the current iteration of a loop and moves to the next iteration.

It does not terminate the loop.

Example: 

for(int i=1;i<=5;i++){

    if(i==3){
        continue;
    }

    System.out.println(i);
}

Output:

1
2
4
5

5️⃣ Can break be used in a switch statement?

Answer:

Yes.

break is commonly used in a switch statement to stop execution after a matching case.

Without break, Java executes the following cases too (fall-though).

Example:

int day = 2;

switch(day){

case 1:
System.out.println("Monday");
break;

case 2:
System.out.println("Tuesday");
break;

case 3:
System.out.println("Wednesday");
break;

}

Output

Tuesday

6️⃣ 5. Can continue be used inside a switch statement?

Answer:

No, continue is not used to control a switch statement itself.

It is only used with loops.

However, if a switch is inside a loop, continue can skip the rest of the current loop iteration.

Example:

for(int i=1;i<=3;i++){

    switch(i){

        case 2:
            continue;

        default:
            System.out.println(i);
    }

}

Output

1
3

7️⃣ 6. What is a labeled break?

Answer:

A labeled break is used to exit an outer loop directly.

It is useful in nested loops.

Example:

outer:

for(int i=1;i<=3;i++){

    for(int j=1;j<=3;j++){

        if(i==2 && j==2){

            break outer;

        }

        System.out.println(i+" "+j);

    }

}

Output:

1 1
1 2
1 3
2 1

The program exits both loops when i == 2and j == 2.

8️⃣ 7. What is a labeled continue?

Answer:

A labeled continue skips the remaining statements odf the current outer loop iteration and starts the next iteration of the labeled loop.

Example: 

outer:

for(int i=1;i<=3;i++){

    for(int j=1;j<=3;j++){

        if(j==2){

            continue outer;

        }

        System.out.println(i+" "+j);

    }

}

Output:

1 1
2 1
3 1

9️⃣ 8. Does break terminate all loops?

Answer:

No.

A normal break terminates only the current(innermost) loop.

To terminate an outer loop, use a labeled break.

Example:

for(int i=1;i<=2;i++){

    for(int j=1;j<=3;j++){

        if(j==2)
            break;

        System.out.println(i+" "+j);

    }

}

Output:

1
3
4
5

1️⃣2️⃣ 11. What happens when continue is executed in a loop?

Answer:

The remaining statements in the current iteration are skipped, and the loop immediately proceeds to the update expression, then checks the loop condition for the next iteration.

Example:

for( int i = 1; i <= 5; i++){
    if(i == 3){
        continue;
    }
    System.out.println(i);
}

Output:

1
2
4
5

1️⃣3️⃣ 12. What happens when continue is executed in a while loop?

Answer:

the remaining statements are skipped, and the loop condition is checked again.

You must ensure the loop variable is update; otherwise, an infinite loop may occur.

Wrong Example:

int i = 1;
while(i <= 5){
    if(i == 5){
        continue;
    }
    i++;
}

this creates an infinite loop because i never changes after becoming 3.

Correct Example:

int i =1;
while(i<=5){
    if(i == 3){
        i++;
        continue;
    }
    System.out.println(i);
    i++;
}

1️⃣4️⃣ 13. Why can continue cause an infinite loop?

Answer:

If the loop variable is not update before continue executes, the loop continue never changes.

Example: 

int i = 1;
while(i <= 5){
    if(i == 2){
        continue;
    }
    i++;
}

Here, i stays 2 forever, causing an infinite loop.

  • Ends infinite loop safely.

  • You want to end an infinite loop.

if( found ){

2️⃣0️⃣ 19. When should you use continue?

Answer:

Use continue when you want to ignore certain values but continue processing the remaining data.

Example: 

if(number < 0 ){
    continue;
}

Negative numbers are skipped.

2️⃣2️⃣ 21. Can break and continue be used together?

Answer:

Yes.

They can appear in the same loop, but only one executes in particular iteration depending on the conditions.

Example: 

for(int i=1;i<=10;i++){

    if(i==3)
        continue;

    if(i==8)
        break;

    System.out.println(i);

}

Output: 

1
2
4
5
6
7

2️⃣3️⃣ 22. Which is faster: break or continue?

Answer:

Neither is inherently faster. they serve different purpose:

  • break can improve performance by ending the loop early.
  • continue skips unnecessary work within an iteration but keeps the loop running.

Performance depends on the program's logic rather than the statements themselves.
