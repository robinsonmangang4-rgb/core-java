Core Java break and continue -Full Course (with Examples and Explanations).

The break and continue statements are jump statements in Java. They control the execution of loops and switch statements.

1. breakStatement

What is break

The break statements is used to immediately terminate a loop or a switch statement.

Once break executes:

  1. The loop stops immediately.
  2. Control moves to the first statement after the loop.

Syntax

break;

Example 1: beak with while loop

public class BreakExample1{
    public static void main(string[] args){
        int i = 1;
        while (i <= 10){
            if (i == 6){
                break;
            }
            System.out.println(i);
            i++;
        }
    }
}

Output

1
2
3
4
5

Explanation

  1. i = 1 → prints 1
  2. i = 2 → prints 2
  3. i = 3 → prints 3
  4. i = 4 → prints 4
  5. i = 5 → prints 5
  6. i = 6 → break executes.
  7. Loop stops immediately.

Example 1: beak with for loop

public class BreakExample2{
    public static void main(string[] args){
        for (int i = 1; i <= 10; i++)
        {
            if(i==7){
                break;
            }
            System.out.println(i);
        }
        
    }
}

Example 3: break in switch.

int day = 2;
switch(day){
    case 1:
        System.out.println("Monday");
        break;

        case 2:
        System.out.println("Tuesday");
        break;

        default:
        System.out.println("invalid");
}

Output

Tuesday

Why break is needed?

Without break, Java continues executing the ext case (fall-through).

2. continue Statement.

Definition

The continuestatement skips the current iteration and moves directly to the next iteration of the loop.

Syntax 

continue;

Example 1: continue with for.

public class ContinueExample1 {
    public static void main(String[] args) {

        for (int i = 1; i <= 5; i++) {

            if (i == 3) {
                continue;
            }

            System.out.println(i);
        }
    }
}

Output

1
2
4
5

Explanation

  1. i = 1 → prints 1
  2. i = 2 → prints 2
  3. i = 3 → When i == 3, continue skips printing.
  4. i = 4 → prints 4
  5. i = 5 → prints 5

Example 2: continue with while.

public class ContinueExample2 {
    public static void main(String[] args) {

        int i = 0;

        while (i < 5) {

            i++;

            if (i == 3) {
                continue;
            }

            System.out.println(i);
        }
    }
}

Output

1
2
3
4
5

Notice that i++ is done before continue. Otherwise, the loop could become infinite.

Difference between break and continue.

Feature break continue
Stop Loop ✅ Yes ❌ No
Skips current iteration ❌ No ✅ Yes
Next iteration continues ❌ No ✅ Yes
Used in switch ✅ Yes ❌ No

Labeled break

A labeled break lets you exit an outer loop directly.

public class LabeledBreak {
    public static void main(String[] args) {

        outer:
        for (int i = 1; i <= 3; i++) {
            for (int j = 1; j <= 3; j++) {
                if (i == 2 && j == 2) {
                    break outer;
                }
                System.out.println(i + " " + j);
            }
        }

        System.out.println("Loop ended.");
    }
}

Output 

1 1
1 2
1 3
2 1
Loop ended.

Real-world Uses

  • break
  • Stop searching once an item in found.
  • Exit an infinite loop when a condition is met.
  • End menu-driven programs when the user chooses "Exit".
  • Prevent unnecessary processing.
  • continue
  • Skip invalid input.
  • Ignore negative numbers during calculations.
  • Process only even or odd numbers.
  • Skip records that don't meet validation rules.

Common Mistakes.

❌ Using continue instead of break

if (found){
    continue;    // Wrong if you want to stop the loop
}

✅ Correct 

if ( found){
    break;
}

❌ Infinite loop with continue. 

int i = 1;
while(i <=5){
    
    if ( i == 3){
    continue;
    }
    i++;
}

i never increments when it is 3, so the loop rus forever.

✅ Correct 

int i = 1;

    if(i == 3){
        i++;

    }
